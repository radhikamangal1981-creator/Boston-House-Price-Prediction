# 🏠 Boston House Price Prediction
A machine learning project built to predict housing prices using key socio-economic and structural features.

### **Technical Summary**
* **Algorithm:** Multiple Linear Regression
* **Key Features:** Rooms (RM), Neighborhood Status (LSTAT), and Pupil-Teacher Ratio (PTRATIO).
* **Validation:** 80/20 Train-Test Split.
* **Performance:** **R² Score of 0.63**.

### **Visual Results**
The model shows a strong correlation between the predicted and actual values, as seen in the final regression analysis plot within the notebook.
